# Demonstration Videos

This directory contains authentic video recordings of the physical sorting system in operation.

## Files

* `test1.mp4`: Single-cycle rapid diversion test of the rotary carousel conveyor, TCS3200 color sensing, transit timing delay, conveyor stop, and dual-flap diversion into sorting chute (Duration: 34.93s, 848x478, 30 fps, 5.78 MB).
* `24BRS1321,1034 Project Video.mp4`: Comprehensive end-to-end multi-package operational sorting demonstration in 1080p Full HD (Duration: 72.60s, 1920x1080, 30 fps, 178 MB). Demonstrates USB power-on initialization, active illumination, and 4 consecutive sorting cycles (2 brown craft boxes, 1 blue parcel, 1 white parcel) into dual diversion chutes with 100% classification and mechanical diversion accuracy. Includes live spoken narration explaining warehouse inventory sorting logic.

  * **Verbatim Audio Transcript:** See [`docs/video_transcript.md`](../../docs/video_transcript.md).
